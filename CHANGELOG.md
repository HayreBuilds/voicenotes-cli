# Changelog

## 1.0.0

- Cross-platform audio recording via sox, arecord, or ffmpeg
- NVIDIA Parakeet CTC 0.6B ASR for accurate English transcription
- Nemotron-Ultra 550B for title, summary, and tag generation
- Markdown notes with YAML frontmatter in ~/voice-notes/
- Fast full-text search across transcript, title, summary, and tags
- JSON index file for sub-millisecond list and search operations
- Tag normalization and deduplication
- 5-minute recording limit with graceful stop
- VNOTE_DIR env var for custom notes directory
- Zero runtime dependencies
